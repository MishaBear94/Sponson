# The documentation site

This directory is the Sponson documentation site, published with [Mintlify](https://mintlify.com). Mintlify does
not publish this file.

## How it is made

Almost every page is **generated** from the Markdown in the repository by
[`scripts/gen-site.ts`](../scripts/gen-site.ts): the README (split into Introduction, Quickstart and Concepts),
SKILL.md, the action's README, `docs/` (plan format, errors, ADRs), `examples/` (with every plan embedded),
CONTRIBUTING.md, ARCHITECTURE.md, SECURITY.md, ROADMAP.md, CHANGELOG.md, and the CLI reference from
`sponson --help`. Generated pages start with a `Generated by scripts/gen-site.ts` comment: do not edit them, edit the
source and run

```bash
pnpm site:gen
```

The generator also rewrites `navigation` in [`docs.json`](docs.json). Everything else in `docs.json` (theme,
colours, logo, navbar) is edited by hand. The pages listed in `HAND_WRITTEN` in the generator (the short guides
under `guides/`) are hand-written too; keep them short and link to the reference pages instead of repeating them.

`scenarios/docs/site.test.ts` (part of `pnpm test`) fails when the site is out of date, when `docs.json` names a
page that does not exist, or when a page has a link that resolves nowhere.

## Preview locally

The Mintlify CLI is not a dependency of the repository. It needs Node.js 20.17 or later:

```bash
npm i -g mint            # or: pnpm add -g mint
cd site
mint dev                 # http://localhost:3000; no login needed (search is disabled until `mint login`)
mint validate            # strict build check: fails on any warning
mint broken-links --check-anchors
mint a11y                # colour contrast and alt text
```

## Publishing (one-time setup, done by the repository owner)

1. Sign in at [mintlify.com](https://mintlify.com) with GitHub and finish onboarding.
2. In the dashboard, open **Settings → Git Settings** and install the Mintlify GitHub App. On GitHub's repository
   selection screen choose **Only select repositories** and pick `MishaBear94/Sponson`.
3. In **Git Settings**, select the repository `MishaBear94/Sponson` and the branch `main`.
4. Turn on **docs.json is in a subdirectory** (the monorepo setting) and enter the path `/site` (no trailing
   slash). Save changes; this triggers the first deployment.

From then on every push to `main` deploys the site, which lives at <https://sponson.mintlify.site>. A custom domain
can be added in the dashboard later.
