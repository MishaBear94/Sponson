# @sponson/core

The engine behind [Sponson](https://github.com/sponson/sponson#readme): the plan model and parser, the planner, the apply/destroy engine with its receipt stores and leases, the redactor, and the `ResourceAdapter` / `SecretSource` interfaces adapters implement.

Most users want the `sponson` CLI instead. See the [project README](https://github.com/sponson/sponson#readme).
