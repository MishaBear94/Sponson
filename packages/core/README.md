# @sponson/core

The engine behind [Sponson](https://github.com/MishaBear94/Sponson#readme): the plan model and parser, the planner, the apply/destroy engine with its receipt stores and leases, the redactor, and the `ResourceAdapter` / `SecretSource` interfaces adapters implement.

Most users want the `sponson` CLI instead. Documentation: <https://sponson.mintlify.site>. Source and issues: [GitHub](https://github.com/MishaBear94/Sponson).
