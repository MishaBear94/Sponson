# @sponson/adapters

The resource adapters and secret sources that ship with [Sponson](https://github.com/MishaBear94/Sponson#readme). `createRegistry()` returns all of them; the [built-in ops](https://github.com/MishaBear94/Sponson/blob/main/docs/plan-format.md#built-in-ops) and [secret schemes](https://github.com/MishaBear94/Sponson/blob/main/docs/plan-format.md#secret-schemes) are listed in the plan format reference. The package also ships the http adapter's [recipes](https://github.com/MishaBear94/Sponson/blob/main/docs/recipes.md) in `recipes/`.

Most users want the `sponson` CLI instead. Documentation: <https://sponson.mintlify.site>. Source and issues: [GitHub](https://github.com/MishaBear94/Sponson).
