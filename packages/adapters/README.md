# @sponson/adapters

The resource adapters (Neon, Vercel, Clerk) and secret sources (`env://`, `doppler://`, `op://`, `aws-sm://`) that ship with [Sponson](https://github.com/sponson/sponson#readme). `createRegistry()` returns all of them.

Most users want the `sponson` CLI instead. See the [project README](https://github.com/sponson/sponson#readme).
