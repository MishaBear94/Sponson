# @sponson/adapters

The resource adapters and secret sources that ship with [Sponson](https://github.com/sponson/sponson#readme). `createRegistry()` returns all of them; the [built-in ops](https://github.com/sponson/sponson/blob/main/docs/plan-format.md#built-in-ops) and [secret schemes](https://github.com/sponson/sponson/blob/main/docs/plan-format.md#secret-schemes) are listed in the plan format reference.

Most users want the `sponson` CLI instead. See the [project README](https://github.com/sponson/sponson#readme).
