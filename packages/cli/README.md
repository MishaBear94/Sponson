# sponson

The Sponson CLI and MCP server: `sponson plan`, `sponson apply`, `sponson init` and `sponson mcp` read `release.plan.yaml` and plan, apply or destroy everything that ships beside the code (database branches, env vars, auth redirects) for one environment and scope.

```sh
npx sponson plan
```

Requires Node.js 22 or later.

Documentation: <https://sponson.mintlify.site> (quickstart, plan format, GitHub Action, agents). Source and issues: [GitHub](https://github.com/MishaBear94/Sponson).
